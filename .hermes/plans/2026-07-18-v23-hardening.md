# hlwy-ai-checker v2.3 Hardening Plan

**Goal:** Improve detection robustness and local proxy safety without breaking the single-file usage model.

**Architecture:** Keep `start.py` + `hlwy-ai-checker.html` entrypoint. Harden proxy. Extend probe protocol/scoring in frontend. Add Python unit tests for security + parse/score helpers.

**Success criteria:**
1. Proxy rejects private/link-local targets and non-allowlisted paths.
2. Default bind is 127.0.0.1; CLI supports host/port/allow-host.
3. Multi-probe protocol with metadata binding on baselines.
4. Strict numeric parse; transport vs parse failures separated.
5. Tests pass; smoke server serves HTML.

**Out of scope:** Full SPA rewrite, official prebuilt baseline packs, CLI headless checker.
